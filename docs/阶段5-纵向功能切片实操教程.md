# 阶段 5 实操教程：按页面功能纵向走通前端闭环、状态机与交互工作台

> 这是一份“边做边理解前端状态流”的实操教程。不要一次性粘贴所有复杂 UI 组件。
> 每个模块只走通一个核心页面或交互闭环；当前模块通过组件测试、浏览器全流程手工验证与 Lint/Build 验收后，才能进入下一模块。

参考设计规范与 UI 提示词见 `docs/image2-前端页面渲染提示词.md`；后端 API 契约见 `docs/api-contract.md`。本教程负责解释“这些前端组件与状态机为什么在此刻出现”。

---

## 1. 学习规则与核心理念

1. **严格分离三类状态**：
   - **服务端状态（Server State）**：来自 API 的不可变数据（Trip、PlanVersion、PlanningRun），通过 REST 端点获取并保持单向流动。
   - **交互与表单状态（Client/Form State）**：用户正在输入的未提交草稿、当前激活的日 Tab、下拉框展开状态、脏标记。
   - **执行与进度状态（Execution State）**：Agent 规划运行时的多阶段推进、实时事件流与可恢复错误。
2. **拒绝盲目做聊天框**：TravelMind 不是简单的 ChatBot，而是可信赖、可复现、有结构化约束的旅行规划工作台。
3. **真实响应式与可打印设计**：兼顾 1440px 桌面端工作台与移动端自适应，最终交付页支持纯净打印样式。
4. **渐进增强与防冲突保护**：每次修改均携带 `base_plan_version`，在前端优雅处理 `409 VERSION_CONFLICT`。

固定实操节奏：

```text
用户交互故事
→ 画状态流与组件树
→ 编写 API Client 与 TypeScript 类型
→ 实现 CSS Module 与 UI 组件
→ 页面路由集成
→ 浏览器手工操作与异常测试
→ 回答深度检查题
→ 提交 Git Commit
```

## 4. 用户故事与数据流

用户在 `/trips/new` 创建旅行：
1. 在出发地与目的地输入框中打字，获得城市联想与时区自动绑定。

3. 点击选择兴趣标签（动漫、美食、城市漫步）和排除项。
4. 调整总预算与每日步行上限滑块。
5. **右侧摘要栏实时同步**所有约束条件与预估预算分配，点击“开始规划”提交并进入下一步。

```text
CityCombobox / DateRangePicker / FormControls
  ↓ (onChange)
formData 局部表单状态
  ↓ (useMemo 计算天数与人均)
TripSummary 实时同步卡片
  ↓ (onSubmit)
createTrip(payload) -> POST /api/v1/trips
  ↓ (201 Created)
router.push(`/trips/${trip.id}/planning`)
```

```tsx
"use client";

import { useEffect, useRef, useState } from "react";
import styles from "./city-combobox.module.css";

export interface CityOption {
  name: string;
  country: string;
  timezone: string;
}

const POPULAR_CITIES: CityOption[] = [
  { name: "东京", country: "日本", timezone: "Asia/Tokyo" },
  { name: "京都", country: "日本", timezone: "Asia/Tokyo" },
  { name: "大阪", country: "日本", timezone: "Asia/Tokyo" },
  { name: "南京", country: "中国", timezone: "Asia/Shanghai" },
  { name: "上海", country: "中国", timezone: "Asia/Shanghai" },
  { name: "北京", country: "中国", timezone: "Asia/Shanghai" },
  { name: "新加坡", country: "新加坡", timezone: "Asia/Singapore" },
  { name: "曼谷", country: "泰国", timezone: "Asia/Bangkok" },
];

interface CityComboboxProps {
  label: string;
  value: string;
  onChange: (city: string, timezone?: string) => void;
  required?: boolean;
  placeholder?: string;
}

export function CityCombobox({
  label,
  value,
  onChange,
  required,
  placeholder = "输入或选择城市",
}: CityComboboxProps) {
  const [open, setOpen] = useState(false);
  const [query, setQuery] = useState(value);
  const containerRef = useRef<HTMLDivElement>(null);

  useEffect(() => {
    setQuery(value);
  }, [value]);

  useEffect(() => {
    function handleClickOutside(e: MouseEvent) {
      if (containerRef.current && !containerRef.current.contains(e.target as Node)) {
        setOpen(false);
      }
    }
    document.addEventListener("mousedown", handleClickOutside);
    return () => document.removeEventListener("mousedown", handleClickOutside);
  }, []);

  const filtered = POPULAR_CITIES.filter(
    (c) =>
      c.name.toLowerCase().includes(query.toLowerCase()) ||
      c.country.toLowerCase().includes(query.toLowerCase())
  );

  return (
    <div className={styles.wrapper} ref={containerRef}>
      <label className={styles.label}>{label}</label>
      <div className={styles.inputContainer}>
        <span className={styles.icon} aria-hidden="true">📍</span>
        <input
          className={styles.input}
          type="text"
          value={query}
          required={required}
          placeholder={placeholder}
          onFocus={() => setOpen(true)}
          onChange={(e) => {
            setQuery(e.target.value);
            onChange(e.target.value);
            setOpen(true);
          }}
        />
      </div>
      {open && filtered.length > 0 && (
        <ul className={styles.dropdown} role="listbox">
          {filtered.map((city) => (
            <li
              key={`${city.country}-${city.name}`}
              className={styles.option}
              role="option"
              aria-selected={city.name === value}
              onClick={() => {
                setQuery(city.name);
                onChange(city.name, city.timezone);
                setOpen(false);
              }}
            >
              <span className={styles.cityName}>{city.name}</span>
              <span className={styles.countryBadge}>{city.country} · {city.timezone}</span>
            </li>
          ))}
        </ul>
      )}
    </div>
  );
}
```

# 模块 2：规划运行状态机与真实事件流追踪

## 8. 用户故事与数据流

用户在创建旅行后，进入 `/trips/[tripId]/planning`：
1. 界面展示进度环（0% → 100%）与当前阶段指示。
2. 垂直时间轴展示规划核心阶段：`解析需求` → `查询天气与POI` → `计算路线矩阵` → `确定性规划与约束检查`。
3. 下方实时事件流日志卡片显示后端生成的真实 `PlanningEventRecord`。
4. 规划成功后，自动平滑跳转至 `/trips/[tripId]` 查看完整草案。
5. 若后端返回不可行约束（422 `NO_FEASIBLE_PLAN`），展示错误原因并提供“放宽约束”返回修改入口。

```text
/trips/[tripId]/planning
  ↓ (挂载时触发)
startPlanning(tripId) -> POST /api/v1/trips/{id}/planning-runs
  ↓ (返回 202 Accepted, run.id)
定时轮询 GET /api/v1/trips/{id}/planning-runs/{run.id}/events
  ↓ (提取 run_started, step_completed, plan_created)
更新进度条与事件流水
  ↓ (run.status === "completed")
router.push(`/trips/${tripId}`)
```

## 9. 规划进度追踪组件实现

新建 `frontend/src/components/trips/planning-progress.tsx`：

```tsx
"use client";

import { useEffect, useState } from "react";
import { useRouter } from "next/navigation";
import Link from "next/link";
import { apiRequest } from "@/lib/api/client";
import { startPlanning, type PlanningRunResponse } from "@/lib/api/trips";
import styles from "./planning-progress.module.css";

interface PlanningEvent {
  id: string;
  sequence: number;
  type: string;
  step: string | null;
  message: string;
  created_at: string;
}

const STEPS = [
  { key: "parse", label: "解析旅行需求与约束" },
  { key: "facts", label: "获取天气、POI与路线事实" },
  { key: "candidate", label: "聚类分区与生成候选行程" },
  { key: "validate", label: "运行确定性约束引擎" },
  { key: "complete", label: "生成旅行计划草案" },
];

export function PlanningProgress({ tripId }: { tripId: string }) {
  const router = useRouter();
  const [run, setRun] = useState<PlanningRunResponse | null>(null);
  const [events, setEvents] = useState<PlanningEvent[]>([]);
  const [error, setError] = useState<string | null>(null);
  const [activeStepIndex, setActiveStepIndex] = useState(1);

  useEffect(() => {
    let timer: NodeJS.Timeout;
    let isMounted = true;

    async function execute() {
      try {
        const initialRun = await startPlanning(tripId);
        if (!isMounted) return;
        setRun(initialRun);

        // 获取生成的规划事件
        const eventsRes = await apiRequest<{ items: PlanningEvent[] }>(
          `/api/v1/trips/${tripId}/planning-runs/${initialRun.id}/events`
        );
        if (isMounted) {
          setEvents(eventsRes.items);
          setActiveStepIndex(STEPS.length);
        }

        // 规划成功后 1.2 秒平滑跳转
        timer = setTimeout(() => {
          if (isMounted) {
            router.push(`/trips/${tripId}`);
          }
        }, 1200);
      } catch (caught) {
        if (isMounted) {
          setError(caught instanceof Error ? caught.message : "规划失败");
        }
      }
    }

    execute();

    return () => {
      isMounted = false;
      clearTimeout(timer);
    };
  }, [tripId, router]);

  return (
    <main className={styles.page}>
      <header className={styles.header}>
        <p className={styles.eyebrow}>TravelMind Agent 规划中</p>
        <h1>正在为你构建可行的旅行方案</h1>
        <p className={styles.subtitle}>
          系统正在综合天气事实、交通耗时与个人约束，进行确定性排期。
        </p>
      </header>

      {error ? (
        <section className={styles.errorCard} role="alert">
          <h2>规划遇到冲突</h2>
          <p>{error}</p>
          <div className={styles.errorActions}>
            <Link className={styles.primaryButton} href={`/trips/new`}>
              修改旅行约束
            </Link>
          </div>
        </section>
      ) : (
        <div className={styles.grid}>
          <section className={styles.card}>
            <h2>规划流程</h2>
            <ol className={styles.stepList}>
              {STEPS.map((step, idx) => {
                const isDone = idx < activeStepIndex;
                const isCurrent = idx === activeStepIndex;
                return (
                  <li
                    key={step.key}
                    className={
                      isDone
                        ? styles.stepDone
                        : isCurrent
                        ? styles.stepActive
                        : styles.stepPending
                    }
                  >
                    <span className={styles.stepIcon}>
                      {isDone ? "✓" : idx + 1}
                    </span>
                    <div className={styles.stepContent}>
                      <p className={styles.stepLabel}>{step.label}</p>
                    </div>
                  </li>
                );
              })}
            </ol>
          </section>

          <aside className={styles.card}>
            <h2>实时执行审计日志</h2>
            <ul className={styles.eventList}>
              {events.length === 0 ? (
                <li className={styles.eventEmpty}>正在初始化规划引擎…</li>
              ) : (
                events.map((ev) => (
                  <li key={ev.id} className={styles.eventItem}>
                    <span className={styles.eventTime}>
                      {new Date(ev.created_at).toLocaleTimeString("zh-CN", {
                        hour12: false,
                      })}
                    </span>
                    <span className={styles.eventMessage}>{ev.message}</span>
                  </li>
                ))
              )}
            </ul>
          </aside>
        </div>
      )}
    </main>
  );
}
```

## 15. 行程微调编辑器核心逻辑

新建 `frontend/src/components/trips/itinerary-editor.tsx`：

```tsx
"use client";

import { useEffect, useState } from "react";
import { useRouter } from "next/navigation";
import Link from "next/link";
import {
  getCurrentPlan,
  submitManualPlanEdits,
  type ManualDayEdit,
  type PlanVersionResponse,
} from "@/lib/api/trips";
import styles from "./itinerary-editor.module.css";

export function ItineraryEditor({ tripId }: { tripId: string }) {
  const router = useRouter();
  const [plan, setPlan] = useState<PlanVersionResponse | null>(null);
  const [selectedDayIndex, setSelectedDayIndex] = useState(0);
  const [dayEdits, setDayEdits] = useState<ManualDayEdit[]>([]);
  const [saving, setSaving] = useState(false);
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    getCurrentPlan(tripId).then((res) => {
      setPlan(res);
      // 初始化编辑草稿
      setDayEdits(
        res.itinerary.days.map((day) => ({
          date: day.date,
          activities: day.activities
            .filter((a) => a.kind !== "transfer")
            .map((a) => ({
              id: a.id,
              title: a.title,
              start_time: new Date(a.start_at).toLocaleTimeString("zh-CN", {
                hour: "2-digit",
                minute: "2-digit",
                hour12: false,
              }),
              end_time: new Date(a.end_at).toLocaleTimeString("zh-CN", {
                hour: "2-digit",
                minute: "2-digit",
                hour12: false,
              }),
              removed: false,
              is_new: false,
            })),
        }))
      );
    });
  }, [tripId]);

  if (!plan || dayEdits.length === 0) {
    return <p className={styles.loading}>正在载入行程编辑器…</p>;
  }

  const currentDayEdit = dayEdits[selectedDayIndex];

  function updateActivity(actIndex: number, field: string, value: string | boolean) {
    const updated = [...dayEdits];
    const target = updated[selectedDayIndex].activities[actIndex];
    updated[selectedDayIndex].activities[actIndex] = {
      ...target,
      [field]: value,
    };
    setDayEdits(updated);
  }

  async function handleSave() {
    if (!plan) return;
    setSaving(true);
    setError(null);
    try {
      await submitManualPlanEdits(tripId, plan.version, dayEdits);
      router.push(`/trips/${tripId}`);
    } catch (caught) {
      setError(caught instanceof Error ? caught.message : "保存修改失败");
    } finally {
      setSaving(false);
    }
  }

  return (
    <main className={styles.page}>
      <header className={styles.header}>
        <div>
          <Link className={styles.backLink} href={`/trips/${tripId}`}>
            ← 返回旅行草案
          </Link>
          <h1>手动调整行程</h1>
          <p>修改活动时间、移除景点或调整顺序；保存后系统将重新校验约束并生成新版本。</p>
        </div>
        <button
          className={styles.primaryButton}
          onClick={handleSave}
          disabled={saving}
          type="button"
        >
          {saving ? "正在校验并保存…" : "保存并生成新版本"}
        </button>
      </header>

      {error && <p className={styles.error} role="alert">{error}</p>}

      <div className={styles.editorGrid}>
        <aside className={styles.daySelector}>
          {dayEdits.map((d, idx) => (
            <button
              key={d.date}
              type="button"
              className={
                idx === selectedDayIndex
                  ? styles.dayBtnActive
                  : styles.dayBtn
              }
              onClick={() => setSelectedDayIndex(idx)}
            >
              Day {idx + 1} ({d.date})
            </button>
          ))}
        </aside>

        <section className={styles.editCard}>
          <h2>{currentDayEdit.date} 活动列表</h2>
          <div className={styles.activityList}>
            {currentDayEdit.activities.map((act, actIdx) => (
              <div
                key={act.id}
                className={act.removed ? styles.actRowRemoved : styles.actRow}
              >
                <input
                  className={styles.titleInput}
                  value={act.title}
                  disabled={act.removed}
                  onChange={(e) =>
                    updateActivity(actIdx, "title", e.target.value)
                  }
                />
                <div className={styles.timeInputs}>
                  <input
                    type="time"
                    className={styles.timeInput}
                    value={act.start_time}
                    disabled={act.removed}
                    onChange={(e) =>
                      updateActivity(actIdx, "start_time", e.target.value)
                    }
                  />
                  <span>至</span>
                  <input
                    type="time"
                    className={styles.timeInput}
                    value={act.end_time}
                    disabled={act.removed}
                    onChange={(e) =>
                      updateActivity(actIdx, "end_time", e.target.value)
                    }
                  />
                </div>
                <button
                  type="button"
                  className={act.removed ? styles.restoreBtn : styles.removeBtn}
                  onClick={() =>
                    updateActivity(actIdx, "removed", !act.removed)
                  }
                >
                  {act.removed ? "撤销删除" : "删除"}
                </button>
              </div>
            ))}
          </div>
        </section>
      </div>
    </main>
  );
}
```

## 21. Markdown 导出与打印样式实现

```tsx
function exportMarkdown(plan: PlanVersionResponse, trip: TripResponse) {
  let md = `# ${trip.destination} · 旅行计划 (版本 ${plan.version})\n\n`;
  md += `> 出发地：${trip.origin} | 同行：${trip.travelers} 人 | 预计总花费：¥${(plan.itinerary.budget.planned_total.amount / 100).toFixed(0)}\n\n`;

  plan.itinerary.days.forEach((day, idx) => {
    md += `## Day ${idx + 1} (${day.date}) · ${day.theme}\n\n`;
    md += `**当日步行**：${(day.statistics.walking_meters / 1000).toFixed(1)} km\n\n`;
    day.activities.forEach((act) => {
      if (act.kind !== "transfer") {
        md += `- **${new Date(act.start_at).toLocaleTimeString("zh-CN", { hour: "2-digit", minute: "2-digit", hour12: false })} - ${new Date(act.end_at).toLocaleTimeString("zh-CN", { hour: "2-digit", minute: "2-digit", hour12: false })}**：${act.title} (${act.kind})\n`;
      }
    });
    md += `\n`;
  });

  const blob = new Blob([md], { type: "text/markdown;charset=utf-8" });
  const url = URL.createObjectURL(blob);
  const link = document.createElement("a");
  link.href = url;
  link.download = `${trip.destination}-旅行计划-v${plan.version}.md`;
  link.click();
  URL.revokeObjectURL(url);
}
```
