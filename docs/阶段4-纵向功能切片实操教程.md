# 阶段 4 实操教程：按功能纵向走通前端、API 与存储

> 这是一份“边做边理解”的教程。不要先创建完整阶段 4 的所有类。
> 每个模块只实现一个用户能实际操作的功能；当前模块通过测试、浏览器和 API 验收后，才能进入下一模块。

完整架构和最终参考代码仍见 docs/阶段4-REST-API与应用层教程.md。本教程负责解释“这些类为什么在此刻出现”。

---

## 1. 学习规则

1. 没有被当前功能使用的类，不创建。
2. 每个模块必须走通前端、HTTP、后端、内存存储，再返回前端。
3. 先写能工作的最小实现，再根据刚遇到的问题重构。
4. 每个模块完成后运行测试，并提交一次 Git。
5. 不为了后续数据库、LLM 或 SSE 提前设计抽象。

固定节奏：

~~~text
用户故事
→ 画数据流
→ 创建最少文件
→ 写后端和存储
→ 写测试
→ 写前端
→ 手工操作
→ 回答检查题
→ 提交
~~~

## 2. 模块路线

| 模块 | 用户现在能做什么 | 本模块才引入的概念 |
| --- | --- | --- |
| 1 | 在网页填写并创建旅行 | CreateRequest、TripRecord、内存字典 |
| 2 | 打开旅行详情页 | GET、404、动态路由 |
| 3 | 点击按钮生成第一版计划 | PlanningRun、应用用例、事实工厂 |
| 4 | 在网页查看每日计划 | PlanVersion、current |
| 5 | 修改步行上限并生成第二版 | FeedbackOperation、版本冲突 |
| 6 | 功能跑通后再重构 | Repository、Service、统一错误、OpenAPI |

不要跳过前面的验收。模块 6 的抽象必须建立在你已经亲手遇到的问题上。

# 模块 1：从网页创建一条旅行

## 4. 用户故事和数据流

用户打开 /trips/new，填写出发城市、目的地和人数。点击“创建旅行”后，页面展示后端生成的 Trip ID、draft 状态和 revision 1。

~~~text
CreateTripForm
→ createTrip()
→ POST /api/v1/trips
→ TripCreateRequest
→ create_trip()
→ 内存字典
→ TripResponse
→ 页面显示 ID 和状态
~~~

现在只需要：

| 名称 | 为什么现在需要 |
| --- | --- |
| TripCreateRequest | 限定浏览器可以提交什么 |
| TripRecord | 表示服务器真正保存的旅行 |
| TripResponse | 限定服务器公开返回什么 |
| 内存字典 | 证明数据真的被保存 |

还不需要 Repository、Service、PlanningRun 或 PlanVersion。

## 5. 创建旅行应用记录

新建 backend/app/application/__init__.py 空文件。

新建 backend/app/application/trips.py：

~~~python
from datetime import UTC, datetime
from enum import StrEnum
from uuid import UUID, uuid4

from pydantic import BaseModel, ConfigDict, Field

from app.domain.trip import TripRequest


class TripStatus(StrEnum):
    """当前只需要创建后的 draft 状态。"""

    DRAFT = "draft"


class TripRecord(BaseModel):
    """服务器保存的旅行资源，不是 HTTP 请求体。"""

    model_config = ConfigDict(extra="forbid")

    id: UUID
    status: TripStatus
    revision: int = Field(ge=1)
    request: TripRequest
    created_at: datetime
    updated_at: datetime


# 第一版故意使用最直观的字典。
# 等后续真的遇到存储分散和测试污染，再重构 Repository。
_TRIPS: dict[UUID, TripRecord] = {}


def create_trip(request: TripRequest) -> TripRecord:
    now = datetime.now(UTC)
    trip = TripRecord(
        id=uuid4(),
        status=TripStatus.DRAFT,
        revision=1,
        request=request,
        created_at=now,
        updated_at=now,
    )
    _TRIPS[trip.id] = trip.model_copy(deep=True)
    return trip


def clear_trips() -> None:
    """测试使用；生产业务代码不调用。"""

    _TRIPS.clear()
~~~

当前功能只有创建，所以状态枚举暂时只有 draft。模块 3 真正出现规划时，再增加 planning 和 needs_review。

## 6. 创建请求与响应

~~~python
from datetime import datetime
from uuid import UUID

from pydantic import BaseModel, ConfigDict, Field

from app.application.trips import TripStatus
from app.domain.common import DateRange
from app.domain.trip import TripConstraints, TripPreferences, TripRequest


class ApiModel(BaseModel):
    model_config = ConfigDict(
        extra="forbid",
        str_strip_whitespace=True,
    )


class TripCreateRequest(TripRequest):
    """客户端创建旅行时允许提交的字段。"""


class TripResponse(ApiModel):
    id: UUID
    status: TripStatus
    revision: int = Field(ge=1)
    origin: str
    destination: str
    destination_timezone: str
    date_range: DateRange
    travelers: int
    preferences: TripPreferences
    constraints: TripConstraints
    locale: str
    display_currency: str
    notes: str | None
    created_at: datetime
    updated_at: datetime
~~~

客户端不能提交 id、status、revision 和创建时间。字段看似相似，但 CreateRequest 表示写入权限，TripResponse 表示公开输出。

## 7. 创建旅行路由

新建 backend/app/api/routes/trips.py：

~~~python
from fastapi import APIRouter, Response, status

from app.api.schemas import TripCreateRequest, TripResponse
from app.application.trips import TripRecord, create_trip

router = APIRouter(prefix="/api/v1/trips", tags=["trips"])


def to_trip_response(trip: TripRecord) -> TripResponse:
    request = trip.request
    return TripResponse(
        id=trip.id,
        status=trip.status,
        revision=trip.revision,
        origin=request.origin,
        destination=request.destination,
        destination_timezone=request.destination_timezone,
        date_range=request.date_range,
        travelers=request.travelers,
        preferences=request.preferences,
        constraints=request.constraints,
        locale=request.locale,
        display_currency=request.display_currency,
        notes=request.notes,
        created_at=trip.created_at,
        updated_at=trip.updated_at,
    )


@router.post(
    "",
    response_model=TripResponse,
    status_code=status.HTTP_201_CREATED,
    operation_id="create_trip",
)
def create_trip_endpoint(
    payload: TripCreateRequest,
    response: Response,
) -> TripResponse:
    trip = create_trip(payload)
    response.headers["Location"] = f"/api/v1/trips/{trip.id}"
    response.headers["ETag"] = f'"{trip.revision}"'
    return to_trip_response(trip)
~~~

Mapper 暂时放在路由文件，因为只有这里使用。等出现重复时再抽取。

~~~typescript
import { apiRequest } from "@/lib/api/client";

export interface Money {
  amount: number;
  currency: string;
}

export interface TripCreateRequest {
  origin: string;
  destination: string;
  destination_timezone: string;
  date_range: {start_date: string; end_date: string};
  travelers: number;
  preferences: {
    interests: Array<{value: string; weight: number}>;
    avoid: string[];
    dietary: string[];
    transport_modes: string[];
    accommodation_notes: string | null;
    pace: "relaxed" | "balanced" | "packed";
    must_visit_place_names: string[];
  };
  constraints: {
    total_budget: Money;
    budget_is_hard_limit: boolean;
    daily_start_time: string;
    daily_end_time: string;
    max_walking_meters_per_day: number | null;
    max_activities_per_day: number;
    minimum_transfer_buffer_minutes: number;
    rest_minutes_per_day: number;
    required_place_names: string[];
    excluded_place_names: string[];
    accessible_only: boolean;
  };
  locale: string;
  display_currency: string;
  notes: string | null;
}

export interface TripResponse extends TripCreateRequest {
  id: string;
  status: "draft";
  revision: number;
  created_at: string;
  updated_at: string;
}

export function createTrip(
  payload: TripCreateRequest,
): Promise<TripResponse> {
  return apiRequest<TripResponse>("/api/v1/trips", {
    method: "POST",
    body: JSON.stringify(payload),
  });
}
~~~

类型暂时手写，是为了亲眼看到前后端字段如何对应。模块 6 再改成 OpenAPI 自动生成。

## 11. 前端创建表单

新建 frontend/src/components/trips/create-trip-form.tsx：

~~~tsx
"use client";

import { useState, type SubmitEvent } from "react";

import {
  createTrip,
  type TripCreateRequest,
  type TripResponse,
} from "@/lib/api/trips";

const DEFAULT_REQUEST: TripCreateRequest = {
  origin: "南京",
  destination: "东京",
  destination_timezone: "Asia/Tokyo",
  date_range: {
    start_date: "2026-10-01",
    end_date: "2026-10-05",
  },
  travelers: 2,
  preferences: {
    interests: [
      {value: "动漫", weight: 1},
      {value: "美食", weight: 0.8},
    ],
    avoid: [],
    dietary: [],
    transport_modes: ["public_transit", "walking"],
    accommodation_notes: null,
    pace: "balanced",
    must_visit_place_names: [],
  },
  constraints: {
    total_budget: {amount: 1_000_000, currency: "CNY"},
    budget_is_hard_limit: true,
    daily_start_time: "09:00",
    daily_end_time: "21:00",
    max_walking_meters_per_day: 12_000,
    max_activities_per_day: 5,
    minimum_transfer_buffer_minutes: 10,
    rest_minutes_per_day: 60,
    required_place_names: [],
    excluded_place_names: [],
    accessible_only: false,
  },
  locale: "zh-CN",
  display_currency: "CNY",
  notes: null,
};

export function CreateTripForm() {
  const [request, setRequest] = useState(DEFAULT_REQUEST);
  const [created, setCreated] = useState<TripResponse | null>(null);
  const [error, setError] = useState<string | null>(null);
  const [submitting, setSubmitting] = useState(false);

  async function handleSubmit(event: SubmitEvent<HTMLFormElement>) {
    event.preventDefault();
    setSubmitting(true);
    setError(null);

    try {
      setCreated(await createTrip(request));
    } catch (caught) {
      setError(caught instanceof Error ? caught.message : "创建失败");
    } finally {
      setSubmitting(false);
    }
  }

  return (
    <section>
      <h1>创建旅行</h1>

      <form onSubmit={handleSubmit}>
        <label>
          出发城市
          <input
            value={request.origin}
            onChange={(event) =>
              setRequest({...request, origin: event.target.value})
            }
            required
          />
        </label>

        <label>
          目的地
          <input
            value={request.destination}
            onChange={(event) =>
              setRequest({...request, destination: event.target.value})
            }
            required
          />
        </label>

        <label>
          出行人数
          <input
            type="number"
            min={1}
            max={6}
            value={request.travelers}
            onChange={(event) =>
              setRequest({
                ...request,
                travelers: Number(event.target.value),
              })
            }
            required
          />
        </label>

        <button type="submit" disabled={submitting}>
          {submitting ? "创建中…" : "创建旅行"}
        </button>
      </form>

      {error && <p role="alert">{error}</p>}

      {created && (
        <div aria-live="polite">
          <h2>创建成功</h2>
          <p>旅行 ID：{created.id}</p>
          <p>状态：{created.status}</p>
          <p>版本：{created.revision}</p>
        </div>
      )}
    </section>
  );
}
~~~

它必须是 Client Component，因为使用状态和事件处理。没有交互的 page.tsx 仍保持 Server Component。

~~~tsx
import { useEffect, useState } from "react";

import {

export function TripDetail({tripId}: {tripId: string}) {

      active = false;

  if (error) {
    return <p role="alert">{error}</p>;
  }
  if (!trip) {
    return <p>正在读取旅行…</p>;

  );
}
~~~

~~~python
        created_at=now,
        finished_at=None,
    )
    _RUNS[run.id] = run.model_copy(deep=True)

    save_trip(
        trip.model_copy(
            update={
                "status": TripStatus.PLANNING,
                "active_planning_run_id": run.id,
                "revision": trip.revision + 1,
                "updated_at": now,
            }
        )
    )

    # 先复用阶段 3 已验证的 fixture 构造函数。
    # 但必须把其中的旧请求替换为当前 Trip.request。
    fixture = build_fixture_facts()
    facts = PlanningFacts(
        request=trip.request,
        places=fixture.places,
        weather=fixture.weather,
        route_matrix=fixture.route_matrix,
        exchange_rates=fixture.exchange_rates,
        planned_at=now,
    )
    outcome = DeterministicPlanner(
        PlannerConfig(max_repair_rounds=max_repair_rounds)
    ).plan(facts)

    if outcome.status != PlanningStatus.FEASIBLE:
        failed = run.model_copy(
            update={
                "status": RunStatus.FAILED,
                "progress_percent": 100,
                "finished_at": now,
            }
        )
        _RUNS[run.id] = failed
        raise RuntimeError("no feasible plan")

    itinerary_data = outcome.itinerary.model_dump(mode="python")
    itinerary_data["trip_id"] = trip.id
    itinerary = Itinerary.model_validate(itinerary_data)

    plan = PlanVersionRecord(
        id=uuid4(),
        trip_id=trip.id,
        version=1,
        itinerary=itinerary,
        constraint_report=outcome.report,
        created_at=now,
    )
    _PLANS[(trip.id, 1)] = plan.model_copy(deep=True)

    completed = run.model_copy(
        update={
            "status": RunStatus.COMPLETED,
            "progress_percent": 100,
            "result_plan_version": 1,
            "finished_at": now,
        }
    )
    _RUNS[run.id] = completed.model_copy(deep=True)

    latest_trip = get_trip(trip.id)
    assert latest_trip is not None
    save_trip(
        latest_trip.model_copy(
            update={
                "status": TripStatus.NEEDS_REVIEW,
                "current_plan_version": 1,
                "active_planning_run_id": None,
                "revision": latest_trip.revision + 1,
                "updated_at": now,
            }
        )
    )
    return completed


def clear_planning_store() -> None:
    _RUNS.clear()
    _PLANS.clear()
~~~

~~~tsx
"use client";

import { useState, type SubmitEvent } from "react";

import { submitWalkingFeedback } from "@/lib/api/trips";

export function WalkingFeedbackForm({
  tripId,
  basePlanVersion,
}: {
  tripId: string;
  basePlanVersion: number;
}) {
  const [meters, setMeters] = useState(1000);
  const [resultVersion, setResultVersion] = useState<number | null>(null);
  const [pending, setPending] = useState(false);

  async function handleSubmit(event: SubmitEvent<HTMLFormElement>) {
    event.preventDefault();
    setPending(true);
    try {
      const result = await submitWalkingFeedback(
        tripId,
        basePlanVersion,
        meters,
      );
      setResultVersion(
        result.planning_run.result_plan_version,
      );
    } finally {
      setPending(false);
    }
  }

  return (
    <form onSubmit={handleSubmit}>
      <label>
        每日最多步行米数
        <input
          type="number"
          min={1000}
          max={50000}
          value={meters}
          onChange={(event) => setMeters(Number(event.target.value))}
        />
      </label>
      <button disabled={pending} type="submit">
        {pending ? "重新规划中…" : "应用反馈"}
      </button>
      {resultVersion !== null && (
        <p>已生成计划版本 {resultVersion}，请刷新查看。</p>
      )}
    </form>
  );
}
~~~

## 43. 第一次重构：Clock

datetime.now(UTC) 已经分散在 trips.py、planning.py 和 feedback.py。创建 Clock：

~~~python
from datetime import UTC, datetime
from typing import Protocol


class Clock(Protocol):
    def now(self) -> datetime: ...


class SystemClock:
    def now(self) -> datetime:
        return datetime.now(UTC)


class FixedClock:
    def __init__(self, value: datetime) -> None:
        self._value = value

    def now(self) -> datetime:
        return self._value
~~~

先只把函数的 now 改成参数，测试传 FixedClock。确认测试通过后再继续。

## 44. 第二次重构：Repository

现在 TRIPS、RUNS、PLANS 和 FEEDBACK 已经证明了需要统一存储。

~~~python
from typing import Protocol
from uuid import UUID


class TravelRepository(Protocol):
    def add_trip(self, trip: TripRecord) -> None: ...
    def get_trip(self, trip_id: UUID) -> TripRecord | None: ...
    def save_trip(self, trip: TripRecord) -> None: ...

    def add_run(self, run: PlanningRunRecord) -> None: ...
    def add_plan(self, plan: PlanVersionRecord) -> None: ...
    def get_plan(
        self,
        trip_id: UUID,
        version: int,
    ) -> PlanVersionRecord | None: ...

    def add_feedback(self, feedback: FeedbackRecord) -> None: ...
~~~

让 InMemoryTravelRepository 包装原来的字典。它不是新功能，只是集中已经存在的存储行为。

## 47. 第五次重构：统一错误

你已经看到 HTTPException、LookupError、ValueError 和 RuntimeError 混在不同路径中。

~~~python
from dataclasses import dataclass, field


@dataclass(slots=True)
class ApplicationError(Exception):
    code: str
    message: str
    status_code: int
    details: list[dict[str, object]] = field(default_factory=list)
    retryable: bool = False
~~~
